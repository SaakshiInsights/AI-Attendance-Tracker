# AI Attendance Tracker

## Overview
A Python and OpenCV-based AI Attendance Tracker that detects faces in real-time through a webcam and automatically records attendance with timestamps in a CSV file.

## Features
- Real-time face detection
- Automated attendance marking
- Webcam integration
- CSV-based attendance storage

## Technologies Used
- Python
- OpenCV
- NumPy
- Pandas

2. Install dependencies
